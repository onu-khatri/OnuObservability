# Security policy

Do not report credentials, tokens, production endpoints, telemetry payloads, or private customer data in a public issue. Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/onu-khatri/OnuObservability/security/advisories/new).

Telemetry capture is metadata-only by default. Security fixes that change signal meaning or remove public API follow the compatibility and versioning policies; urgent mitigations may disable an unsafe signal while preserving application work.
