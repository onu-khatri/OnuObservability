# Support

Supported usage covers the documented public APIs on the declared runtime matrix. Generic Host background services, ASP.NET Core applications, and MCP servers are supported; a console-specific adapter is not provided.

Support requests and reproducible defects are handled through [GitHub Issues](https://github.com/onu-khatri/OnuObservability/issues). Do not use public issues for vulnerabilities or sensitive telemetry data; follow [SECURITY.md](SECURITY.md) instead. No response-time commitment is made for prerelease packages.
